## أُنجز: المهام (القسم 28)
- مهام بحالات `open/assigned/in_progress/review/accepted/cancelled`، والمسؤول يبدأ ويسلّم، والإدارة تقبل بنتيجة مكتوبة أو تلغي بسبب (مفروض في القاعدة أيضًا).
- مهمة من بطاقة مشكلة بمسودة من خطوتها وفحوصها، ومهمة مرتبطة بمشكلة مالية لا تظهر لمن لا يقرأ المالية، والتكلفة لمن يملك `finance.read_summary` فقط.
- 6 اختبارات API + 3 domain + تجربة متصفح.
