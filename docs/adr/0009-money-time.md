# ADR-0009: المال والوقت

- **التاريخ:** 2026-10-10 · **المالك:** المهندس المسؤول والمالية · **الحالة:** معتمد

- **المبالغ:** `NUMERIC(20,6)` للحساب و`NUMERIC(18,6)` للكميات. لا `float` أبدًا. في JSON تُرسل نصوصًا عشرية (`"250.00"`). التقريب النهائي حسب دقة العملة، وطريقته ومكانه موثقان.
- **العملات:** الأصل يُحفظ دائمًا. لا جمع لعملتين قبل تحويل موثق بسعر وتاريخ ومصدر محفوظ.
- **الوقت:** كل الأحداث بتوقيت UTC، والفترات التقويمية تُحسب بمنطقة المتجر (افتراضيًا `Asia/Riyadh`)، وتُكتب الفترة `[start, end)`.
- **الغياب:** القيمة المفقودة `null`، ولا تتحول إلى صفر. ونسبة التغير على أساس صفري لا تُحسب.
- **السجل المالي:** append-only مع حركات عكسية، ولا حذف فعلي (القسم 31).
