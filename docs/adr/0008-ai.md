# ADR-0008: الذكاء الاصطناعي

- **التاريخ:** 2026-10-10 · **المالك:** المهندس المسؤول · **الحالة:** معتمد

**القرار:** Claude API (Anthropic) عبر وحدة `ai` مقيّدة. لا تصل إلى قاعدة البيانات ولا إلى أسرار OAuth مباشرة؛ تستقبل مدخلات محددة مسبقًا (allowlisted) مُنقّاة حسب دور المستخدم، وتُرجع JSON مطابقًا لمخطط، ولا يُنفَّذ ناتجها كأوامر.

**القواعد (القسم 46):** النموذج لا يحسب الأرقام المالية ولا يعتمد إنفاقًا. كل تشغيل يُسجَّل بإصدار الموجّه (prompt) والنموذج والتكلفة. سقف تكلفة لكل مؤسسة. محتوى المنافسين والملفات مدخل غير موثوق، ومحمي من حقن التعليمات (AC11).

**الأثر:** يُحدد اسم النموذج وإصداره عند التنفيذ من التوثيق الحالي، ولا يُكتب ثابتًا مخفيًا في الكود.
