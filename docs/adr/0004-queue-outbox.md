# ADR-0004: الطوابير وصندوق الأحداث

- **التاريخ:** 2026-10-10 · **المالك:** المهندس المسؤول · **الحالة:** معتمد

**القرار:** طابور المهام **pg-boss** داخل PostgreSQL نفسها، مع جدول `outbox` يُكتب في نفس المعاملة (transaction) التي تغيّر البيانات.

**الخيارات:** Redis + BullMQ (مقترح الوثيقة)، أو طابور مُدار (SQS)، أو pg-boss.

**السبب:** الوثيقة تشترط transactional outbox وأن «قفلًا موزعًا وحده لا يكفي» (القسم 37). حين يكون الطابور داخل القاعدة نفسها، يصير تغيير البيانات وجدولة المهمة ذريًا بلا تنسيق بين نظامين، ونستغني عن خدمة كاملة إضافية. والحجم المستهدف في E1 (10 متاجر و100 ألف طلب) مناسب تمامًا.

**الأثر:** العمّال يدعمون at-least-once مع إزالة التكرار بمفاتيح فريدة. ننتقل إلى Redis أو طابور مُدار بـ ADR جديد إذا أثبتت المراقبة أن الحمل يحتاجه.
