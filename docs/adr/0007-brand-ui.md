# ADR-0007: الهوية في المنتج

- **التاريخ:** 2026-10-10 · **المالك:** صاحب المنتج · **الحالة:** معتمد

**القرارات:**
- **الشعار الرئيسي:** «نرسي نمو متجرك». **التحريري:** «من الفكرة إلى الأثر».
- **الخطوط:** Gamila Arabic (مرخّص ومشترى) للعربية، وManrope (OFL) للاتيني والأرقام، لأن جميلة لا تحتوي حروفًا لاتينية.
- **الأرقام:** غربية (0–9) متساوية العرض في الجداول. الأرقام الهندية تفضيل للمستخدم لاحقًا.
- **العملة:** رمز الريال السعودي الرسمي كأيقونة SVG (`brand/icons/riyal.svg`)، و`SAR` في التصدير.
- **الوضع الافتراضي فاتح**، والداكن مدعوم بألوان مفحوصة مستقلة.
- **ألوان الرسوم:** 7 ألوان فئوية مفحوصة آليًا لعمى الألوان والتباين في الوضعين.

**المرجع:** `brand/README.md` و`brand/tokens.css`.
